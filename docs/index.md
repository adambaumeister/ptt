# Python-To-Tools (PTT)

<figure markdown="1">
![logo](static/logo.svg)
</figure>

<p style="text-align: center;">
Python-to-tools is a simple library for implementing agentic handling of python objects and functions.

It's designed to be the 'magic glue' between normal, programmatic functions, allowing them to be used in more
dynamic and natural ways.
</p>

![GitHub commit activity](https://img.shields.io/github/commit-activity/w/adambaumeister/ptt)
![GitHub License](https://img.shields.io/github/license/adambaumeister/ptt)


## Install

=== "Pip"
    ```shell
    pip install python-to-tools
    ```

=== "Poetry"
    ```shell
    poetry install python-to-tools
    ```
